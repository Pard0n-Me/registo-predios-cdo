# Registo de Prédios CdO
Webapp (PWA) para registar prédios, frações, visitas porta a porta, pessoas e anúncios em Campo de Ourique.
Vite + React + TypeScript · Supabase · Leaflet/OpenStreetMap.

- Especificação: `../especificacao-v0.md`
- Configuração: `CONFIGURAR.md`
- Esquema da base de dados: `supabase/schema.sql`
- Sem variáveis `VITE_SUPABASE_*` a app arranca em modo demonstração (dados fictícios no aparelho).

Regra: este repositório **não** contém dados pessoais reais (estão só na base de dados).
